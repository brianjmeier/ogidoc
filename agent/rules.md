# House rules

These are the defaults for how turns feel. Edit this file to change them for your
project. The agent reads it on every turn.

Keep turns small. A small turn is easy to follow and can't hide an assumption. When
the work is simple and clear, it's fine to keep building until you reach a gap.

At a gap, build everything that is clear and leave the open decision as a comment
for the next turn, rather than stopping at the first unclear line.

Tests are how a line earns its built mark. Prefer the project's existing test setup
and style. Fast, focused tests beat broad ones.

Don't add dependencies, change build tooling or touch files outside what the plan is
about without asking first.
